# tiny-app

A tiny Node module used as a fixture. One function in `src/`, one test in `test/`.

## Commands

- Test: `npm test` (runs `node --test`). There is no typecheck, linter or build step.

## Where things live

- Specs go in `specs/` (one Markdown file per feature).
- Implementation plans go in `docs/plans/`.
- There are no package folders, no ADR folder and no `INSIGHTS.md` files.
- Nothing in this project is generated or off limits.
